## 설치형 릴리스 기반

- 서명된 NSIS 설치 파일과 Tauri updater manifest를 제공합니다.
- 사용자 실행 경로는 설치된 앱을 기준으로 합니다.

## 데이터 보호

- 앱 데이터는 `%APPDATA%\com.wronganswer.notebook`에 유지됩니다.
- 설치와 업데이트는 저장된 학습 데이터와 이미지를 변경하지 않습니다.

## 설치형 실행 전환

- 일반 사용자 실행은 설치된 시작 메뉴 앱만 사용하며 Node.js, npm, Rust, Cargo 또는 source build를 실행하지 않습니다.
- 앱 내부 updater는 서명된 GitHub Release artifact만 설치합니다.

## 데이터 보호

- 설치, 업데이트, 제거와 재설치에서 `%APPDATA%\com.wronganswer.notebook`의 학습 데이터와 이미지를 유지합니다.
- 과거 source build 산출물은 별도 읽기 전용 진단 도구로만 확인할 수 있습니다.
