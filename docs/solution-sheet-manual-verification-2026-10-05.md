## 구현

### 데이터 보호

1. 그래프 로드 결과를 boolean으로 전달한다. 복원 시작에 이전 로드 세대를 무효화하고 저장 권한을 회수한다. 유지보수 구간에서 쓰기를 기다린 뒤 백업을 적용한다. 필요한 재로딩이 모두 성공해야 저장을 허용한다. 실패 상태의 편집 UI도 차단한다.
2. 그래프 자체의 다시 불러오기와 복원 재시도 모두 같은 유지보수 구간을 이용한다. 실행 잠금을 동기적으로 설정해 중복 진입을 막는다.
3. 가져오기 항목 ID를 미리 정하고 초안에 pending 확정 기록을 먼저 저장한다. 저장 콜백에는 그 ID를 전달한다. 완료 기록이 남으면 편집·되돌리기·자동 저장을 막고 정리 재시도와 완료 후 닫기만 허용한다.
4. 재진입 시 저장소의 ID를 대조한다. 모두 있으면 초안 정리만 수행하고, 결과가 불확실하면 항목을 추가하지 않는다. 읽기·복구·폐기·재저장의 실패 Promise와 실행 잠금을 처리한다.
5. 자동 저장, 수동 저장, 폐기, 확정과 초안 읽기는 같은 쓰기 순서를 따른다. 단일 문제지도 보호되는 작업실 경로를 사용한다.
6. 답안 수정 후 누락 문항 안내를 다시 계산한다. 빈 화면의 조사를 수정했다.

### 파란 점과 해설창

- 연결 편집 화면에서 페이지를 처음 열면 점 위치 후보를 검출한다. 위치 추가·끌어서 이동·삭제, 문항 선택, 명시적 연결 확인을 제공한다. 자동 후보는 해설 버튼으로 활성화되지 않는다. 가져오기 초안에는 후보를 보관하고 항목에는 확인한 연결만 저장한다.
- 문항 키는 정규화한 번호와 구분을 사용하며 해당 항목에 한정된다. 키가 중복되면 확인을 요구하고 번호만으로 모호한 답안을 붙이지 않는다. 문항 번호 수정·자료 간 이동에서 잘못된 연결이 남지 않게 처리했다.
- 원본 이미지 위의 비율 좌표 클릭 영역은 최소 32px다. 인접 영역이 겹치면 문항 선택 창을 제공한다. 원본 이미지는 재작성하지 않는다.
- 흰색 80% 높이 해설창, 고정 손잡이·문항 번호·이전/다음·전체 높이·닫기, 독립 본문 스크롤을 제공한다. 손잡이 드래그, 키보드, 버튼을 지원하고 닫은 뒤 점으로 포커스를 돌린다.
- 정답·명시적 출제 의도·해설을 기존 수식/그림 렌더러로 표시한다. 없는 내용은 연결 안내를 제공한다. 정답 가리기는 문항별 명시적 열기 전까지 유지한다.
- 다음 해설의 확인된 페이지가 선택돼 있으면 함께 이동한다. 없으면 현재 페이지를 유지하고 안내한다. 첫·마지막 화살표는 비활성화하며 창 높이는 유지한다.
- 학습, 연습, 제출한 시험에서 사용한다. 진행 중 실전에서는 해설 버튼과 렌더링을 차단한다. 제출 후에는 저장한 snapshot의 답안·그림을 사용한다. MCP 공개 문항에서도 새 비공개 답안 필드를 제거한다.
- ZIP 원본 이미지는 파일 미리보기, Windows staged 이미지는 인증된 내부 미리보기 경로로 읽는다.

## 코드 검토로 확인한 범위

- 생성 시험은 원문 키로 확인한 점을 snapshot에 복사하고 시험 위치 번호와 새 snapshot ID로 다시 연결한다. 서로 다른 자료의 원문 1번을 번호만으로 합치지 않는다.
- 새 optional 필드가 없는 항목·snapshot·초안을 기존대로 읽는다. 원본과 기존 주석을 변환하거나 이전하지 않는다.
- 항목의 점 페이지와 snapshot의 해설 그림이 자산 참조 보호·이름 변환 경로를 통과한다. Rust의 extra 데이터와 기존 JSON 백업 형식을 이용한다.
- 방향키/손잡이/점 이벤트와 페이지 넘김 이벤트를 분리한다. 기존 텍스트·이미지 주석 경로는 유지했다.

## 남은 제한과 후속 확인

- 제공한 PDF는 51페이지의 이미지 PDF다. 전체 PDF의 OCR·해설 자동 추출은 구성된 분석 제공자가 없어 실행하지 않았다. 실제 원본 이미지와 사람이 검토한 1~5번 문항·해설을 사용했다. 스크린샷의 다른 버전 수식으로 답안을 만들지 않았다.
- 실제 터치 장치, Windows 네이티브 창에서 staged 이미지·백업의 전체 실행 경로, 모든 저장 지연 순열은 미확인이다. Rust 컴파일과 코드 경로를 확인했다.
- 생성 시험의 여러 자료·중복 번호, 겹친 클릭 영역, 손상된 그림, 기존 주석 작성·삭제의 모든 조합을 직접 조작한 것은 아니다. 자동 회귀 검사는 사용자 요청에 따라 실행하지 않았다.
- 브라우저 재로딩/재진입으로 복구를 확인했으며 Windows 프로세스 강제 종료·재시작까지 검증했다고 주장하지 않는다.
- 기존 Draft들의 기능 전체와 다양한 PDF 배치에 대한 통합 검토는 별도다. 이번 수동 경로에서 새 P0/P1은 재현하지 않았지만 위 제한을 근거로 자동 병합 준비 완료로 판정하지 않는다.
- `entryPaneOverrides` 정리는 삭제 취소·복원 이후 확정 시점이 필요한 별도 P3 작업이다.
