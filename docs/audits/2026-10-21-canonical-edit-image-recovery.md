## 저장과 호환성

- 본문은 기존 정규화 함수와 segment 편집기를 재사용한다. 그림·표·조건·반복 수식과 segment ID, 원본 페이지 출처를 보존한다.
- 호환 문자열은 최초 원문을 기준으로 유일하게 대응되는 부분만 갱신한다. 공통 지문과 호환 원문에만 있는 문장을 보존한다. 선택지 추가·삭제도 양쪽에 반영하며 정답 연결 확인을 안내한다.
- 생성 시험 번호와 원문 번호가 다른 단일 snapshot 및 기존 단일 segment-key alias를 지원한다. 여러 후보 중 첫 문항을 고르지 않는다. 중복·미확정 연결은 원문과 검토 안내를 유지한다.
- 기존 필기는 같은 텍스트 범위를 정확히 확인할 수 있을 때만 위치를 옮긴다. 삭제되거나 모호해진 필기 범위가 있으면 저장을 중단하고 입력을 보존한다. 필기나 구조화 정보를 일괄 삭제하지 않는다. 이미지 필기는 그대로 유지한다.
- 공개 저장 형식·API·일괄 마이그레이션은 추가하지 않는다. 기존 자료는 읽을 수 있고 변경한 항목만 기존 필드에 저장한다.

## 직접 사용

격리 브라우저의 합성 자료로 1100×750 라이트 모드와 680×750에서 확인했다.
