## 제공 ZIP의 전후 측정

원본 문제지·도형을 포함한 사용자 제공 ZIP을 로컬 격리 브라우저에서 사용했다. 사용자 자료는 커밋하지 않았다. 기존 production baseline과 수정본에 같은 흐름을 실행했다. axe 실행 전에 CDP/Long Tasks 값을 수집했다.

| 관측 시점 | 이전 | 수정본 |
|---|---:|---:|
| 30문항 텍스트 전환 직후 DOM 요소 | 8,892 | 1,117 |
| 같은 시점 KaTeX 요소 | 154 | 4 |
| 해당 구간 최대 Long Task | 1,925ms | 610ms |
| 집중 보기 + 배경 DOM | 9,947 | 3,354 |

지연 렌더링 후 인쇄 준비 이벤트에서 본문 마운트 수가 **4→30**으로 확장됐다. 헤더는 항상 존재하므로 마지막 문항 이동과 문항 선택이 가능하다. 이 수치는 한 PC의 localhost 단일 관측이며 INP·네이티브 속도·정상 상태 전체 DOM·메모리 누수 판정은 아니다. 이후 스크롤로 본문을 읽으면 마운트 수는 늘어난다. 초기 번들 약 1.80MB 및 기존 chunk 경고는 남아 있다.

## 증거와 남은 범위

로컬 산출물은 Git 제외 `build/diagram-pipeline/ui-quality/`에 둔다. performance-only.json, final-a11y.json, production 및 인앱 화면, 빌드 로그를 포함한다. 접근성 검사에서 기존 색상 위반은 선택한 화면에서 사라졌고, 스크롤 영역의 키보드 진입 누락을 발견해 tabindex/이름을 보완했다. 자동 검사 미완료 판정은 전체 접근성 통과로 해석하지 않는다.

공개 저장 형식·이미지 선택·Import 승인/확정 기록·원본 자산은 변경하지 않았다. 실제 AI 제공자/유료 API, 설치 앱의 키 저장·호출, 네이티브 창·터치, 원본 PDF 전체의 OCR·수학적 동일성은 이번 확인 범위 밖이다. 기존 P3인 대형 번들·린트 경고·entryPaneOverrides 정리는 별도다. 병합과 설치판 교체는 수행하지 않는다.
