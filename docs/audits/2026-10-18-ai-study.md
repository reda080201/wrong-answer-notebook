## 구현

### 출처

생성 snapshot에 선택적 `sourceReference`, 생성 시험·세션에 선택적 `showSourceReferences`를 추가했다. 생성 번호와 원문 번호를 구분하고 생성 당시 제목·회차·영역을 표시한다. 기존 세션은 생성 시험의 문항과 유일하게 대응할 때 표시용 출처를 보충한다. 제목 변경·원본 삭제 후에도 저장된 출처를 유지한다. 이동할 수 없거나 번호가 모호하면 안내한다.

출처는 생성 미리보기, 텍스트 시험지, 집중 보기, 원본 페이지 바깥 영역과 인쇄·내보내기에 표시한다. 생성 시험의 출처 표시 선택이 생성 출력의 기본값을 결정하며, 출처표 방식도 지원한다. 이미지 파일에 출처를 직접 그리지 않는다.

### AI 구성

기존 생성 화면에서 직접 구성과 AI 구성을 선택한다. 자유 구성과 편집 가능한 수능형 수학·국어·영어·탐구 틀을 제공한다. 이는 앱 템플릿이며 공식 범위·선택과목·듣기 자료의 완전성을 보증하는 기능이 아니다.

사용자가 지정한 문제지·문항에서 후보를 구성한다. 과목·검토 상태·정답/해설 연결·출처당 제한·문항 수·배점·난이도별 수·단원별 수·중요도를 지정할 수 있다. 후보가 많으면 중요도 선택과 공통 지문 묶음을 반영해 최대 80문항을 검토하며 미검토 범위를 표시한다. 더 큰 범위는 나누어 검토한다.

AI는 문항 ID·배점·순서·선정 이유만 반환한다. 본문·그림·수식·표·원본 페이지는 로컬 snapshot에서 복사한다. 허용 범위 밖·중복 원문·잘못된 배점·출처 제한·공통 지문 누락/순서 변경·고정 문항 변경·난이도/단원 조건 위반을 거부한다. 후보가 부족해도 조건을 자동 완화하지 않는다. 미평가 점수를 사용자 평가로 덮어쓰지 않는다. 고정·제외/복구·순서 변경·대화 요청 수정·초안 저장·검토 후 저장/풀기를 제공한다.

### 대화와 저장

새 대화는 자료 없이 시작한다. 작은 AI 버튼으로 여는 패널은 넓은 화면에서 CSS 크기 조절을 제공하고 700px 이하에서는 전체 화면으로 전환한다. 대화 목록·새 대화·이름 변경·삭제·중지·재시도와 수식/코드 표시를 제공한다.

사용자가 현재 문항·선택 문항·문제지·문제은행을 첨부한다. 출처·단원·난이도·중요도가 함께 전송됨을 표시하고 본문·선택지·그림·정답·해설·메모·학습 기록을 각각 선택한다. 정답·해설과 그림은 기본 제외한다. 정답/해설 전송은 허용 확인, 그림 전송은 모델의 입력 지원 확인을 거친다. 화면 문항 이동은 첨부 자료를 자동 교체하지 않는다.

범위를 변경하면 새 문맥 ID를 사용한다. 이전 답변은 새 요청에 포함하지 않으며 당시 첨부 자료와 옵션은 로컬 기록에 보존한다. 진행 중 실전 시험의 원본 자료 전송과 연결된 이전 답변 표시를 차단한다. 제출한 시험은 저장된 snapshot을 사용한다. AI에 저장/수정 도구를 제공하지 않으며 사용자 버튼 조작만 시험을 저장한다.

`ai-study.json` / `wrong-answer-ai-study-v1`에 버전 1 기록과 구성 초안을 저장한다. 대화와 구성 초안의 쓰기는 하나의 대기열에서 병합하여 서로 덮어쓰지 않는다. 손상된 기록은 보존하고 쓰기를 차단한다. 유지보수 구간은 신규 쓰기를 막고 진행 중 쓰기를 기다리며 늦은 AI 응답을 무효화한다. 이전 문맥·구성 초안까지 이미지 참조 보호에 포함한다.

수동 백업의 대화 포함은 기본 해제다. 제외 시 대화만 사용하는 이미지도 백업에서 제외하며 다른 자료와 공유하는 이미지는 포함한다. 대화가 없는 백업을 복원할 때 기존 대화와 첨부 이미지를 유지하고 파일명/내용 충돌은 중단한다. 명시적으로 대화를 포함한 백업에서만 대화 기록을 교체한다.

### API 연결

기존 제공자·모델·OS 키 저장을 재사용한다. `request_study_ai`, `cancel_study_ai`, `load_ai_study_store`, `save_ai_study_store`를 handler와 permission에 함께 등록했다. OpenAI 계열·Gemini·Anthropic 스트림과 사용자 지정 호환 endpoint의 일반 응답을 처리한다. 취소는 실제 HTTP future를 중단하고 요청 ID별로 구분한다. API 키를 대화·프런트엔드 payload에 저장하지 않는다.

고정 한도: 후보 80문항/요청, 그림 최대 20개·파일당 10MiB·전체 14MiB, 자료 텍스트 180,000바이트, 이력 60메시지·240,000바이트, 응답 2MiB, 로컬 AI 기록 16MiB. 제공자별 토큰 한도는 별도다. 모델별 그림 지원·요금은 사용자가 설정한 제공자에 따른다.

## 직접 사용 중 추가로 수정한 사항

1. 공유 옵션의 `images: boolean`을 이미지 파일 목록으로 오인하여 첫 대화 저장을 거부하던 검증 충돌을 수정했다. 이미지가 있는 snapshot만 참조 형식 검사를 받는다.
2. 출처 이동 시 비동기 항목 선택보다 문항 요청이 먼저 설정되어 다른 문항이 선택되던 경로를 기존 탐색 절차에 항목 ID·섹션·문항 요청을 함께 전달했다. 개발 모드의 effect 재실행에서 초기화와 소비한 요청 상태가 달라 지정 문항이 초기값으로 돌아가는 경로도 수정했다.
3. 대화에서 저장하고 풀기 후 구성창이 시험 위에 남는 경로를 닫고 실제 시험으로 전환한다.
4. 원본 보기의 고정된 세 행 레이아웃에 출처 줄이 별도 행으로 삽입되어 가려지던 문제를 도구 영역으로 묶어 수정했다. 텍스트 시험지의 출처 버튼은 포커스 이동이 먼저 문항을 바꾸지 않게 했다.
5. 직접 선택한 텍스트 보기에서 다음 문항으로 이동할 때 원본 보기로 바뀌며 답안 클릭이 누락될 수 있어, 같은 시험 안에서는 사용자의 텍스트 선택을 유지한다. 미연결 문항의 자동 텍스트 기본값은 유지한다.
