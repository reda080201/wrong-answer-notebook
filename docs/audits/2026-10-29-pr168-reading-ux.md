# PR #168 읽기·검색·검토 UI 후속 수정

기준: `4110be2`. 브라우저 격리 모드와 공개 합성 자료만 사용했다. 실제 데이터, API, 설치판은 변경하지 않았다.

## 변경과 직접 확인

- 문항별 화면의 중복 표지·제목·통계를 제거하고 문항 목록을 도구 모음으로 통합했다. 과목·태그·텍스트 검수는 유지한다. 구조화 문항의 목차 스크롤 대상도 실제 canonical 요소로 연결했다.
- 동일한 2문항 합성 자료의 첫 본문: 1100×750에서 약 574px → 327.7px, 680×750에서 첫 화면 밖 → 418.5px. 본문 글꼴은 16.8px로 동일하다. 좁은 도구 모음은 글자를 세로로 자르지 않고 버튼을 줄바꿈한다.
- 라이트/다크 두 크기를 직접 열었다. 목차의 Enter 이동으로 현재 문항 2/2와 GPT 질문 번호가 함께 변경되는 것을 확인했다. 설정 Escape 닫기와 포커스 복귀도 확인했다.
- AI 검색 결과 추가는 기존 첨부 1번을 유지하면서 검색된 2번만 추가했다. 다시 눌러도 2문항이며, 없는 검색어에서는 0문항 버튼이 비활성화됐다. 유료 API 호출은 하지 않았다.
- 정상 문항에는 완료 버튼 대신 상태를 표시한다. 오류·미확인 답·그림 검토를 완료 버튼으로 우회할 수 없다.
- 공개 `diagram-pipeline-v7.zip`을 실제 선택해 작업실을 열었다. 본문/선택지 원본 그림 600×600, 원본 비교 600×600, 정리본 후보 1000×650의 실제 로드를 확인했다. 그림 검토 미완료 시 완료 버튼은 비활성화됐다. 저장 버튼은 실행했지만 이후 브라우저 제어가 중단돼 이 ZIP의 저장 완료·재진입은 이번 직접 점검에서 확정하지 않는다.
- 보조 메뉴는 스크롤 영역 안에서 펼쳐지는 배치로 제한했다. 마지막 메뉴 배치 수정 이후 직접 화면 재확인은 브라우저 제어 중단으로 미확인이다.

## 최소 검사

- 관련 4개 파일 64건 중 첫 실행 62통과/2실패. 상세 헤더 축소로 과목 정보와 텍스트 검수 버튼이 함께 사라진 회귀를 발견해 복구했다. 상세 파일 49건 재실행은 전부 통과했다. 나머지 3개 파일 15건은 최초 실행에서 통과했다. 테스트 삭제·skip·timeout 증가는 없다.
- 최초 빌드는 새 테스트에 잘못 넣은 RTL `exact` 옵션으로 실패했다. 해당 옵션만 제거한 뒤 TypeScript/Vite 빌드 통과. 최종 메뉴 CSS 포함 빌드 결과는 제출 보고를 따른다.
- 전체 lint: 오류 0, 경고 59. CSS 소유권/릴리스 계약 5건 통과. 전체 테스트·E2E·Rust·Python은 반복 실행하지 않았다.
- 원본/A4와 기본 표지는 변경하지 않았으며, 앱 읽기 화면에만 내부 `showCover` 옵션을 적용했다. 인쇄 시 표지 복원, 기본 표지 및 A4 모드 분리는 회귀 검사로 확인했다. 실제 PDF 출력, 실물 터치, 설치판은 이번 직접 점검에서 미확인이다.

## 제한

실자료 수학적 정확도, 긴 수식·한글 라벨의 모든 조합, 다수 학습 후보의 고정 버튼 전체 흐름을 이번 점검으로 보증하지 않는다. 대규모 가상 스크롤·새 의존성·저장 형식 변경은 하지 않았다. PR은 Draft로 유지하고 병합하지 않는다.
