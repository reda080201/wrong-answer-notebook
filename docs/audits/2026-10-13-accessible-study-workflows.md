## 기준과 범위

- 기준: `origin/main=cbe7f13d41cf4867366e91d684479013a8932591`.
- 브랜치: `codex/accessible-study-workflows`.
- 최신 main에 #148과 #150이 이미 포함되어 있어 해당 변경을 다시 적용하지 않았다.
- 독립 작업 공간과 독립 `npm ci`를 사용했다. 사용자 작업 폴더, 다른 작업 공간의 미커밋 변경, 데스크톱 앱 데이터는 변경하지 않았다.
- 저장 형식·백업 형식과 공개 API, 원본 PDF 표시 방식은 변경하지 않았다. 그래프 갱신 콜백에 내부 함수형 갱신을 추가했다.
- 메모리 제한에 따라 관련 단위 검사만 worker 1개로 실행했다. 전체 단위 검사·E2E·Rust·Tauri 빌드와 설치판 교체는 이번 로컬 확인에서 제외했다.

## 로컬 검사

| 검사 | 결과 |
| --- | --- |
| 독립 `npm ci --no-audit --no-fund` | 성공, 285개 패키지 설치 |
| 관련 단위 검사 9개 파일, `--maxWorkers=1` | **77/77 성공**, skip 없음 |
| 변경 TS/TSX 파일 ESLint | 성공, 오류 0개. 경고는 아래 기록 |
| `npm run test:css-ownership` | **3/3 성공** |
| `npm run build` | 성공. 기존 dynamic/static import 및 큰 chunk 경고 유지 |
| `git diff --check` | 성공 |

관련 파일: `EntryDetail`, `StudyPaperView`, `ImportPreviewSummary`, `MathText`, `LearningContentPanel`, `useKnowledgeGraph`, `KnowledgeGraphView`, `OnboardingTour`, `NotificationProvider`.

첫 실행에서 변경된 UI 의미를 반영하지 못한 검사와 새 테스트 코드의 타입 오류를 발견했다. 체크박스 이름은 삭제 문구를 제외한 정확한 이름으로 검사하고, 수식은 제거한 일반 aria-label 대신 실제 MathML 및 문장 순서를 검사하며, 접힌 시각화는 펼친 뒤 확인하도록 바꿨다. 별칭 실패 재시도용 가짜 저장소의 실패 플래그는 callback 캡처에 고정되지 않도록 ref로 유지했다. 시작 안내 종료/바로가기 뒤의 초기화도 검증했다. 기대하는 제품 동작을 유지하며 모두 다시 통과시켰다. 테스트 삭제·skip·timeout 증가는 없다.

ESLint 경고 8개 중 EntryDetail의 7개는 기존 경고이며, KnowledgeGraphView의 1개는 유지보수로 쓰기가 차단될 때 삭제 취소 상태를 폐기하는 effect의 setState 경고다. 이 초기화는 복원 전 별칭의 실행 취소가 복원 후 그래프에 적용되는 것을 막기 위해 유지했다.

## 직접 사용 결과와 증거

브라우저 격리 모드 `127.0.0.1:1460`에서 1100×750 라이트 모드로 실제 앱의 등록→저장→편집→이미지 추가→집중 보기 평가→새로고침→삭제→실행 취소를 사용했다. 실제 저장소까지 연결된 항목과 그림이 복구됐다.

다섯 단계 시작 안내, 9개 가져오기 사유, 3개 시각화, 체크리스트, 다중 알림은 **실제 제품 컴포넌트를 불러오는 임시 수동 확인 화면**에서 확인했다. 그래프는 같은 화면에서 실제 useKnowledgeGraph와 격리 저장소를 사용했다. 이 화면의 자료는 확인용이며 전체 가져오기·시험 흐름의 검증으로 확대해 해석하지 않는다. 임시 화면 코드는 제출에서 제거했다.

680×750에서는 알림 배치 및 그래프의 세로 배치와 가로 넘침을 확인했다(`clientWidth=scrollWidth=680`). 다크 그래프도 별도로 확인했다. 임시 서버와 브라우저 탭을 닫고 viewport 설정을 해제했다.

## 제한과 후속 작업

- 실제 스크린 리더의 한국어 수식 낭독, 물리 터치, Windows native 앱 조작은 미확인이다. DOM/MathML 검사를 실제 낭독 검사로 보고하지 않는다.
- 전체 단위 검사·E2E·Rust·Tauri의 로컬 재실행은 메모리 제한으로 보류했다. 동일 head의 GitHub CI 결과는 PR에서 별도로 확인해야 한다.
- 다른 AI 보고서의 시험 닫기·생성 시험 삭제·타이머 관련 주장은 기존 저장/확인/시각 계산 코드와 대조해 이번 수정 대상에서 제외했다. 흰색 해설창은 요청된 디자인을 유지했다.
- 가상화·입력 debounce·SettingsContext 분리는 실제 측정과 별도 설계가 필요하다. 의존성 변경 및 entryPaneOverrides 정리도 포함하지 않았다.
- 이번 범위의 직접 사용과 관련 검사에서는 새로운 P0/P1을 발견하지 않았다. 앱 전체에 문제가 없다는 판정은 아니다.
- Draft로 제출하며 병합하지 않는다. 전체 검사 및 동일 head CI 확인 전에는 최종 병합 준비 완료로 판정하지 않는다.
