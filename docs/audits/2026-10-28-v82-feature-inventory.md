# v8.2 기능 인벤토리 및 요구사항 추적 — 정적 코드 감사

기준: checkout HEAD `e4f44cb184eed88eb3ac02d1a0d12f46284c3490`; 사용자 제공 v8.2 프롬프트와 현재 작업 트리의 코드·테스트 경로를 대조했다. v8.2 작업 트리에는 Vision/Import 관련 변경이 미커밋 상태다. 이 문서는 코드 위치와 테스트 존재를 조사한 정적 감사이며 테스트·빌드·앱·API·CLI를 실행하지 않았다. 따라서 “테스트 파일 존재”는 실행 통과가 아니며 모든 실행 결과는 **미실행**이다. v8.1 보고서(`docs/audits/2026-10-27-v81-implementation.md`)의 과거 결과는 그 문서가 기록한 당시 head에만 해당한다.

## 판정 기준 및 요약

`기존 정상 / 수정 필요 / 부분 구현 / 미구현 / 확인 불가` 중 하나를 코드 계약의 범위에 따라 정했다. `기존 정상`도 이번 감사의 런타임 정상 판정을 뜻하지 않는다. 사용자 요청의 보존 여부는 데이터 모델·호출 경로가 남아 있는지에 대한 정적 판단이다. 전체 목표는 **부분 구현**: 사전 GPT 풀이→평가→답안 대조 데이터 계약과 원본-only/CLI 패키징 경로가 있으나, 실제 GPT 정확도 및 앱 왕복은 미실행이고 혼합 PDF 페이지 역할, 호스트 실행 증명 전달 및 전체 회귀도 추가 확인이 필요하다.
