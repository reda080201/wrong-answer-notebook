## 수정

- **숨겨진 AI 패널과 키보드 충돌:** DOM에 남아 있어도 숨김·inert·aria-hidden 상태인 창은 집중 보기의 키보드 우선순위에서 제외한다. 포커스 목록도 실제로 조작 가능한 요소만 포함한다. Tab은 집중 보기 안에서 순환하고, Escape로 닫으면 표시 중인 원래 실행 버튼으로 돌아간다. 중첩 해설창이 먼저 처리한 키는 다시 처리하지 않는다.
- **작동하지 않는 분할선:** 저장된 분할 비율을 CSS grid의 실제 열 폭에 연결했다. 해설 최소 340px·문제 최소 400px을 유지하고, 1100px 이하에서는 기존 세로 배치를 사용한다. 보이는 선은 1px이며 실제 조작 영역은 18px로 넓혔다. 드래그 외에 좌우 방향키와 Home/End를 지원하고, 조절 범위·현재값을 접근성 속성으로 제공한다. 기존 45–72 비율과 저장 키를 재사용한다.
