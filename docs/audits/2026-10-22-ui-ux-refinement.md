## 저장·보호 범위

- 항목·시험·백업 형식, 확정 기록·해시·고정 ID 판정은 변경하지 않는다.
- 미리보기만 임시 이미지 resolver를 사용한다. 원문 위치의 그림 ID와 순서는 공통 렌더러를 재사용한다. 임시 파일 URL은 파일 객체별로 재사용하고 대상이 사라지거나 종료되면 해제한다. 영속 이미지 캐시의 URL을 정리하지 않는다.
- 수식 표시만 조정하며 저장 본문·segment ID·주석 좌표를 재작성하지 않는다. `\\begin`, `\\end`, `\\left`, `\\right`를 사용한 식과 중첩된 큰 간격은 자동 행 분리에서 제외한다.
- AI의 전송 경계·공유 동의·실전 자료 차단은 기존 구현을 사용한다. 새 헤더 버튼은 대화창만 연다.
- PDF/ZIP의 전사 오류와 누락은 자동 복원하지 않는다. 제공 ZIP20번의 원문 조건 차이와 축약 과정은 별도 자료 검토가 필요하다.
