## 구현

- vision-v1 호환과 별도의 엄격한 vision-v2, TS/Python 공통 허용·거부 23개 사례.
- 실제 파일 해시·역할에 묶인 관측 3페이지 배치, 풀이→점수 평가를 모든 문항에 마친 뒤 답안지 대조. 실패 시 평가 캐시를 보존하고 취소 응답은 반영하지 않는다.
- 공식 OpenAI endpoint·GPT 모델·완결 응답·실제 response ID를 Rust에서 확인한 요청에만 실행 증거를 발급한다. 외부 JSON/CLI ZIP의 자기선언은 imported로 남긴다.
- 점수 1~100 정수, 신뢰도 0~100, 미평가 null+이유. 점수·근거·전략·개념은 원본-only/CLI 양쪽으로 저장한다. 수동 점수·중요 false·품질점수는 보존한다.
- 예상 답/충돌 답은 저장·학습 가능하지만 시험 시작·제출에서 자동 채점을 차단한다. 저장된 항목/생성 시험에서 명시적 정답 확인 후 시작한다. 원문 답과 예상 답은 각각 유지한다.
- 평가 재시도 기록은 현재 webview의 별도 localStorage에 보존한다. 원본 바이트는 재선택해야 하며 해시·역할이 다르면 덮어쓰지 않는다. 저장 실패 시 현재 창의 결과를 유지하고 다음 유료 요청을 중단한다.
- 외부 CLI 결과의 GPT 출처를 자동 복원하는 승인 경로는 만들지 않았다. 대응하는 실제 호스트 실행 증명이 없는 결과는 외부 분석으로 표시한다.
