# 직접 점검 5건 후속 수정

- 하단 학습 바에 AI 진입을 통합하고 floating launcher를 숨긴다. 기존 대화 열기 이벤트와 포커스 복귀를 재사용한다.
- 시험 진입 때 해당 자료 객체의 원본/텍스트 선택과 현재 문항을 임시 보관한다. 복귀 후 해제하며 원본 최초 기본값은 유지한다. StrictMode 복귀 검사 포함.
- 720px 이하에서 선택한 자료의 목록을 자동 접고 목록 복귀를 제공한다. 일반 오답의 학습 흐름은 기본 접기이며 제목·메타데이터·중첩 패널 여백을 줄인다.
- 목록/상세/AI 출처의 표시 제목을 공통화한다. 본문으로 자동 생성된 제목은 수식 토큰을 제거한 요약을 사용한다. 실제 저장 제목·원본 출처 상태를 바꾸지 않는다.
- AI 빈 대화 안내를 첨부·무첨부·연결 불가 상태로 구분한다.

## 확인 결과

- 관련 최종 회귀: 상세 50건, 제목 1건 통과. 첫 관련 실행의 기존 2건 회귀는 임시 위치 기록의 공유 범위를 줄여 해결했다. 신규 복귀 검사 첫 실행은 jsdom ResizeObserver 누락이어서 기존 원본 보기 검사와 동일한 observer/scrollTo fixture를 제공했다. 기대값 완화나 테스트 삭제는 없다.
- 전체 lint 최초 오류 1건(렌더 중 ref 읽기)은 수정했다. 수정 파일 재검사 오류 0건. 기존 경고는 유지했다. CSS 소유권 3건·diff 검사 통과. TypeScript/Vite 빌드 통과 후 최종 코드 빌드는 PR 제출 결과를 따른다.
- 680px 다크 격리 브라우저에서 목록 자동 접기, 공통 제목, 접힌 학습 흐름, floating 버튼 숨김, 통합 AI 버튼의 실제 열기와 닫은 뒤 포커스 복귀를 확인했다. 저장된 합성 자료만 사용했고 API 전송은 하지 않았다.
- 전체 앱/E2E/Rust/Python 검사는 반복하지 않았다. 최종 1100px·라이트 재확인과 첫 본문 420px 목표의 정확한 최종 실측은 미완료다. 실제 설치판·터치·실전 시험 전체 흐름도 미확인이다.
- 원본 보기 선택 복원은 현재 앱 실행 중 시험 진입/복귀에 한정한다. 앱 재시작 후 문항 위치를 새 저장 필드로 영구 보존하는 기능은 추가하지 않았다.
