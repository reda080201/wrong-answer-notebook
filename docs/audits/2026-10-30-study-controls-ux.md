## 재현과 수정

- 높이900px 이하의 공통 CSS가 열린 하단 도구까지 숨겼다. 무조건 숨김을 제거하고 열린 바의 높이·스크롤을 제한했다. 680/1100×750에서 다시·어려웠음·메모 표시를 실제 확인했다. 메모 입력 후 저장 버튼 활성화 확인, 입력은 비우고 저장하지 않았다.
- 단일 오답의 이전/다음은 숨기고 하단 버튼 글자를14px, 높이를36px(좁은 화면40px) 이상으로 조정했다. 680px에서 실제14px/40px 확인.
- 제목 아래 분류·날짜를 한 행으로 묶고 학습 흐름을 더보기에서 요청한 경우에만 표시한다. 1100px까지 일반 오답의 목록도 자동 접고 목록 복귀는 유지한다.
- 같은 합성 문항의 첫 본문 위치는1100px에서381.27→299.19px, 680px에서427.66→345.58px. 격리 브라우저 라이트 모드 수치이며 본문 글꼴은 유지했다.
- AI 자료 범위 검토 시 대화·작성 영역을 접고 옵션·검색을 고정한 채 자료 목록을 스크롤한다. 선택 완료/첫 Escape는 대화로, 다음 Escape는 패널 닫기 및 진입 버튼 포커스 복귀. 680/1100px에서 확인했다. 사용자 범위 변경은 기존 동의·문맥 변경 경로를 그대로 사용한다.
- 환경 미지원 여부를 연결 상태에 전달해 브라우저에서 무의미한 API 설정 버튼과 반복 설정 안내를 제거했다. 실제 원인 메시지는 한 곳에서 표시한다.
